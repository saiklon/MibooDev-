# NANO OS — Prototype 001

Prototipo web interactivo inspirado en el Apple iPod nano 3G (A1236, 4 GB).

## Publicación
Sitio estático preparado para GitHub Pages mediante GitHub Actions.

## Ejecutar localmente
Abre `index.html` en un navegador moderno. No requiere instalación ni servidor.

## Controles
- Click Wheel: MENU, anterior, siguiente, play/pause y botón central.
- Teclado: flechas, Enter, Escape, Espacio y M.
- También admite interacción táctil en la rueda.

## Alcance
Simulación de interfaz y navegación en HTML/CSS/JavaScript. No es firmware y no controla el iPod físico.
Los módulos Fotos, Juegos y Notas son pantallas de demostración para futuras iteraciones.
